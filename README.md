# Сайт IGS Outdoor — igsoutdoor.kz

Статический сайт: HTML + CSS + JS, без базы и серверного кода. Владелец репозитория — IGS Outdoor.
Этот репозиторий — единственный источник сайта. Всё, что попадает в ветку `main`, автоматически
выкладывается на хостинг (Plesk, PS.kz) в течение минуты.

## Состав
- `*.html` — страницы (главная `index.html`, продукты, `articles.html` и статьи `article-*.html`)
- `styles.css`, `enhancements.css` — оформление
- `script.js` — меню и анимации; `i18n.js` — тексты интерфейса
- `assets/` — фото (webp/jpg), видео (mp4), логотипы
- `robots.txt`, `sitemap.xml` — для поисковых систем

## Как вносить изменения
1. Создать ветку от `main`: `git checkout -b <тема>` (например `article-pergola-winter`).
2. Внести правки, проверить локально (открыть `index.html` в браузере).
3. Отправить ветку: `git push -u origin <тема>` и открыть Pull Request в GitHub.
4. После одобрения и merge в `main` сайт обновится сам. Напрямую в `main` писать нельзя.

## Новая статья
1. Скопировать любой `article-*.html`, заменить содержание, `title`, `description`, `canonical`.
2. Добавить карточку статьи в `articles.html`.
3. Добавить адрес статьи в `sitemap.xml`.

## Правила
- Никаких паролей, ключей и токенов в репозитории — он публичный.
- Один Pull Request — одна тема.
- Контакты, цены и названия партнёров на сайте менять только по согласованию с владельцем.
- Фото — webp до ~300 КБ; видео — до ~15 МБ. Тяжёлые файлы обсуждать до загрузки.
- Адрес сайта в `canonical`, `robots.txt`, `sitemap.xml` — всегда `https://igsoutdoor.kz`.

## Кто ведёт сайт
- Владелец: IGS Outdoor (аккаунт GitHub `igsoutdoor-cmd`) — одобряет изменения, управляет доступами, хостингом и доменом.
- Техническая часть: добавляется строкой ниже первым учебным Pull Request.
