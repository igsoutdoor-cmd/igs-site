# Правила работы с сайтом IGS Outdoor

## Что за сайт

- Сайт компании IGS Outdoor (Алматы): https://igsoutdoor.kz.
- Алан ведёт техническую часть сайта.
- Репозиторий GitHub: `igsoutdoor-cmd/igs-site`, ветка `main` защищена. Всё, что слито в `main`, через минуту появляется на сайте; больше ничего делать не нужно.
- Сайт статический: страницы `*.html` в корне, стили `styles.css` и `enhancements.css`, скрипты `script.js` и `i18n.js`, картинки и видео в `assets/`, `sitemap.xml`, `robots.txt`. Серверного кода, сборки и базы нет.
- Статьи: `articles.html` — список карточек, `article-*.html` — сами статьи.

## Как работаем

1. В `main` не коммитим никогда. На каждую задачу новая ветка от `main`: `article-<тема>`, `fix-<тема>`, `update-<тема>`, латиницей через дефис.
2. Одна задача = одна ветка = один Pull Request. Темы не смешивать.
3. Перед PR проверяем: страницы открываются, ссылки и картинки на месте, новая страница добавлена в `sitemap.xml`.
4. Перед созданием PR показать Алану список изменённых файлов и что в них.
5. Pull Request в `main`. Название по-русски: «Статья: …», «Правка: …», «Обновление: …». Описание четырьмя строками:

   ```text
   Что сделано: …
   Зачем: …
   Что проверить: …
   Проверено: да
   ```

6. Замечания владельца в PR правим в той же ветке, новый PR не открываем.
7. Слияние выполняет владелец. После merge ничего не делаем.
8. Отвечать Алану коротко, по-русски, по шагам. Если задача нарушает правило из этого файла, остановиться и сказать об этом.

## Новая статья

- Копируем структуру любой `article-*.html`: `head`, шапка, текст, кнопка WhatsApp, подвал.
- Имя файла: `article-<тема>.html` латиницей.
- `title` до 60 знаков, заканчивается на «— IGS Outdoor»; `description` до 160 знаков; `canonical` — `https://igsoutdoor.kz/<файл>`.
- В JSON-LD заполнить `headline`, `description`, `url`, `datePublished`.
- Один `h1`, разделы `h2`, абзацы по 2–4 предложения, по-русски, факты только из материалов IGS, без цен.
- Картинки: `assets/<имя>.webp` до 300 КБ, `alt` заполнен.
- Карточка первой в `articles.html`, строка в `sitemap.xml`.

## Нельзя

- Менять телефон, WhatsApp, Instagram, названия партнёров, цены без указания владельца.
- Класть в репозиторий пароли, ключи, данные клиентов: репозиторий публичный.
- Удалять и переименовывать файлы, трогать `index.html`, `styles.css`, `script.js`, `i18n.js` без задания.
- Менять адрес сайта в `canonical`, `robots.txt`, `sitemap.xml`: всегда `https://igsoutdoor.kz`.
